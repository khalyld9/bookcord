Admin flow — the desk, audited

Admin-only view. Starts at /login?desk=admin → requireAdmin guard → Overview → 5 desks: Inventory, Reservations, Claim Desk (QR scan), Checkouts, and Chat Inbox. Every inventory write is an audited RPC with a row in stock_movements.

🔐 Guards

middleware → updateSession + requireAdmin on every page & server action. Non-admins redirect to /books.

📦 RPCs

restock_book +N • issue_book on claim • return_book on return • adjust_inventory ± correction. All write stock_movements.

💬 Chat

Student → STUDENT, Admin → ADMIN. Inbox groups by profile_id, live via Supabase Realtime.

💡
QR claim — 6 steps

Student reserves → PENDING + QR → Admin marks READY → student shows QR → Admin scans at /admin/claim → claimReservation validates + issue_book → CLAIMED → inventory updated.
